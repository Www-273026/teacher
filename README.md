# ESG理论与实践：第一章绪论

面向本科课堂的中文 PowerPoint 课件，涵盖 ESG 概念与体系、发展历程、与 SDGs 的关系，以及中国实践意义。内容依据公开资料独立整理，并非教材原文。

## 生成课件

```bash
python -m pip install -r requirements.txt
python scripts/generate_esg_intro.py
```

生成文件：[`ppt/ESG理论与实践_第一章_绪论.pptx`](ppt/ESG理论与实践_第一章_绪论.pptx)。课件中的文字、图形和表格均可在 PowerPoint 或兼容软件中编辑；参考资料页含有可点击的来源链接。
